# 12-report

When the run ends, whether it shipped, parked, or stopped, write one report with `pipeline/report-template.md`.

Gather first:

- The implementer's decision lines. Copy them in as written.
- The run's deferred notes. A note reaches the owner only if a reviewer agrees it could not be fixed in the run. Step 09 asked the reviewer for a ruling line on each. A note with no ruling counts as not agreed, so ask the reviewer again. A note the reviewer says could have been fixed goes back to the implementer, not to the owner.
- Anything only the owner can decide, which the template asks you to price.

File nothing yourself: no issue, no label. The report is where the owner learns of it.
