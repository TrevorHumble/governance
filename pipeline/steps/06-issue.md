# 06-issue

The owner said approve and the hook showed an `Approved:` line for your issue. Run to the merged PR with no check-ins, except an owner call a later step names.

If the hook refused the tag, the issue is not approved. Say so in one line and ask again. The issue reviewer at step 07 does not start on an issue without `owner-approved` (`spawn-check`, `WHAT-IT-CHECKS.md`).
