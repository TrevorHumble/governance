# 08-implement

Read the `implementing` skill now and build the passing issue by it, with the paths of any prior art step 03 found. The work is yours, and no other agent builds it.

Keep the decision lines the skill asks for: step 11 copies them into the PR body and step 12 into the report.

When the build is done, run `npm run check:budget` before any review, so an overage is caught before anyone reviews or pushes. CI runs it again as the backstop.

If it fails, read the check's own message and follow it; it says what needs the owner's yes. Tightening your own change's new text needs no yes.
