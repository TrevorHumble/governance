# Owner declines

The owner's recorded leave-it-alone answers to report notes, so the owner is asked once. Only the owner's answer adds a line. `tools/note-check-core.ps1` holds the exact-match test. This file holds declines for notes about this repo; another repo's declines go in its own file.

Format, one line per decline:

```
- YYYY-MM-DD - <normalized one-line substance> - <the owner's answer, in their words>
```

The " - " separator is part of the line. Replace any " - " inside the answer with ", " so the substance field parses back out exactly.
