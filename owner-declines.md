# Owner declines

The owner's recorded leave-it-alone answers to report notes, so he is asked once
(`agents/orchestrator.md` § "No agent files its own issue" rule 4 owns the recording rule; rule
2's pre-checks read this file before any note may exist). One line per decline: the date, the
note's normalized one-line substance verbatim, and the owner's answer. Only the owner's answer
puts a line here; no agent adds one on its own initiative. An item recorded here is never raised
again. This file records declines for notes belonging to this repo; a note belonging to another
repo is recorded in that repo's own `owner-declines.md`.

Format:

```
- YYYY-MM-DD - <normalized one-line substance> - <the owner's answer, in his words>
```

The " - " separator belongs to the line's structure: the recorder replaces any " - " inside the
answer with ", " so the substance field always parses back out exactly.
