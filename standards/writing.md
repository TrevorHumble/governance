# Writing

## Cut what does not earn its place

No opening line that restates the heading. No padding. If a section can be one line, make it one line. Bloat is a finding only when the reviewer can quote the sentence that could go without losing meaning.

## A finding quotes its evidence

Quote the line, the word, or the output. A finding without a quotation is not a finding.

## Names

No FINAL, LAST, or TRULY_FINAL in file names or headings. The next change makes them false. Use a version or a date.

## Filler words

CI checks the banned words: run `npm run check:banned`. The list lives in the check, not here.
